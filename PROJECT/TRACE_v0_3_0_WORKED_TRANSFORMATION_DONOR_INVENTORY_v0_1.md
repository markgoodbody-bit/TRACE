## Rule

A worked transformation is retained for the structural capability it tests, not because its topic or prose is historically familiar.

```text
CASE_TEXT_PRESENT != CAPABILITY_PRESERVED
NEW_EXAMPLE_COUNT != BETTER_TRANSFER_SUITE
TOPIC_MATCH != REGRESSION_COVERAGE
```

Disposition vocabulary:

```text
EXACT_CARRY       donor case can survive except declared version-identity updates
CARRY_AND_TIGHTEN retain donor case and add/replace only the minimum assertions needed for earned v0.3 repairs
PROFILE_CARRY     retain as an explicitly bounded profile/transfer case, not universal centre
OPEN              capability coverage not yet settled
DROP              forbidden without separate redundancy proof
```

No case currently earns `DROP`.
