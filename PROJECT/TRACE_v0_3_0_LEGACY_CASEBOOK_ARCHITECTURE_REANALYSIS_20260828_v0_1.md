## 2. Methodological limits already admitted by the casebook

The casebook itself records several defects that materially limit inference:

- synthetic fixtures test responses to stipulated worlds, not field effectiveness;
- AI-only evidence cannot establish benefit to human professionals or affected people;
- the first `TRACE-off` controls were contaminated because they already contained compressed TRACE anti-shortcut distinctions;
- later work corrected the design to `C0 ordinary / C1 generic structured / T1 TRACE`;
- fixtures were cue-heavy;
- one negative control was explicitly labelled as such;
- cases were generated and only partially independently reviewed;
- no masked adjudication was completed;
- model identity/truncation/input problems affected several returns;
- the corpus was small;
- the testing loop initially continued after the main signal had stabilised and was later stopped.

Therefore:

```text
CASEBOOK != EFFICACY PROOF
MODEL RETURN != HUMAN PRACTITIONER EFFECT
SAME DECISION != SAME REVIEW QUALITY
MORE ACCOUNTING != BETTER DECISION
```

## 3. Case-level evidence

### Case 000 — Last Two Pumps

Pilot only.

- one clean matched pair chose the same allocation;
- most operational findings were already present in competent ordinary review;
- TRACE made external value priority more explicit;
- TRACE strengthened the commitment receipt and correction-vs-restoration distinction;
- full participant-facing TRACE created substantial context/output load;
- treatment induced over-application / unsupported certainty in at least one aperture.

The experiment itself responded by abandoning full-source practitioner use and creating a bounded application profile.

**Architecture signal:** strong against `more formal source = better practitioner interface`; weakly for a smaller accountability overlay.

### Case 001 — Rent Bridge / usable correction route

Method-limited null/mixed result because the supposed controls already encoded central TRACE distinctions.

- controls found the key route/timing distinction;
- treatment added more visible unresolved claims, safeguards, downstream burden/residue and commitment accounting;
- no clean matched treatment discovered a new material route defect, option or decision;
- Gemini/Qwen treatment outputs also expanded into unsupported system failures, psychological effects, other populations, fraud/legal claims.

Casebook verdict: no demonstrated material advantage over compressed TRACE; credible incremental gain was accountability, not decision discovery.

**Architecture signal:** if compact ordinary language already carries the useful distinctions, the formal profile must justify additional burden by something stronger than conceptual coverage.

### Case 002 — Harborline remediation closure

This is the cleanest direct architecture pressure in the early set because it used distinct C0/C1/T1 arms.

All clean arms selected the same proportionate option.

C0 ordinary review already found:

- excluded denominator/population;
- unsupported closure claim;
- evidence-deletion deadline;
- targeted remediation rather than indiscriminate rollback/compensation.

C1 mainly improved claim/source organisation.

T1 TRACE did not change the decision. Its strongest output added:

- proof-burden transfer;
- practical complaint-route analysis;
- burden/residue separation;
- explicit commitment receipt.

But the treatment did not robustly discipline weaker models: unsupported distress, deception, regulators, legal consequences and wider systemic harm were still introduced.

Casebook verdict: candidate narrow TRACE advantage, unadjudicated; accountability and closure honesty rather than main-decision discovery; too model-dependent for a robust claim.

**Architecture signal:** supports an accountability-overlay hypothesis, not a superior decision-method claim.

### Case 003 — ColdChain negative control

All arms made the same ordinary-operation decision.

TRACE's strongest output improved commitment/restraint, but across providers it did not reliably prevent:

- `zero harm` overstatement;
- causal overstatement;
- invented monitoring;
- invented thresholds;
- overclaim about control effectiveness.

Casebook verdict: model-dependent restraint, not robust method advantage.

**Architecture signal:** a structured profile can itself create category pressure. Anti-overfire must be part of product evaluation, not treated as a solved property of the grammar.

### Case 004 — RouteSure

Only the ordinary arm was run.

The ordinary baseline found every pre-registered material proposition, including:

- confirmed/reproducible defect;
- clinical vs non-clinical burden distinction;
- separate affected/preventive/preference populations;
- reactive-route vs prevention distinction;
- temporary evidence vs durable validation;
- simulation vs field result;
- burden transfer from over-constraining the whole population;
- reimbursement != restoration.

The project **stopped** rather than running generic/TRACE arms automatically.

The casebook says this was the point where the process acquired a stopping rule: another synthetic arm would have to improve calibration/accountability rather than merely rediscover the obvious decision.

**Architecture signal:** competent ordinary review can fully occupy some cases. TRACE must remain conditionally useful, not compulsory.

## 4. Cross-case result already present in the historical evidence

The casebook's own synthesis is unusually aligned with the 2026-08-28 nearest-neighbour pressure:

### Main decision discovery was not the differentiator

Across the usable small corpus, TRACE did not demonstrate superior discovery of the main decision.

### Generic structure mainly improved legibility

Regularising claim scope, sources, thresholds, owners and triggers helped presentation/inspection, but did not produce stable calibration improvement and could increase pressure to populate categories or invent thresholds.

### Recurring TRACE signal: answerability

The casebook concentrated the candidate value into:

```text
boundary / exclusions
external priority
route usability before hardening
evidence custody / future proof burden
burden and residue
selector and authority
commitment receipt
category refusal
```

### Recurring adverse signal: category-driven extrapolation

The profile could induce:

```text
unsupported population expansion
unsupported psychological/legal/systemic claims
intent/governance inference from structural omission
simulation -> field-proof collapse
new data collection because a category is empty
invented thresholds / review programmes
formal-route overread or unsupported capture claims
```

### Model discipline dominated method effects

The same profile behaved materially differently across receiver families.

### The bounded profile was still probably too large

The casebook explicitly proposed a shorter accountable-review insert rather than a larger profile or larger case library.

## 5. Historical seven-step compression

The casebook's practical compression was:

1. **Boundary** — decision, horizon, included population, exclusions, blind spots.
2. **Evidence state** — observed/reported/inferred/disputed/unknown; framework label is not evidence.
3. **Route and clock** — who can use/carry authority and whether correction can arrive before hardening.
4. **Targeting** — affected/protected/preventive/preference populations and under/over-inclusion costs.
5. **Burden and residue** — what is created, relieved, transferred and left behind; correction/payment/restoration remain distinct.
6. **External priority** — identify the value/clinical/legal/operational rule selecting the option; do not attribute it to TRACE.
7. **Commitment receipt** — selected action, selector, authority, unresolved claims, open routes, review triggers and reasons the decision may prove wrong.

With one explicit anti-expansion law:

> Do not add a finding, field, threshold, programme, harmed population, legal consequence or systemic claim merely because a category exists.

This was **working implication, not canon**, and was not itself tested as a treatment.

## 6. Reinterpretation after FPF / STPA / ISO pressure

The 2026-08-28 nearest-neighbour pass found zero established TRACE-unique semantic primitives in its current comparison. Mature neighbours can recover nearly all constituent distinctions.

The casebook supplies an independent historical reason not to panic about that result: the observed candidate value had already concentrated in **selection / activation / accountability**, not main-decision novelty.

But it also raises the standard further.

The architecture hypothesis should now be:

> TRACE may justify continued maintenance only if its specialised compilation improves answerability / omission resistance / transfer enough to outweigh its category pressure, context cost and population burden.

This is much narrower than `TRACE is a better general decision method`.

## 7. Architecture outcomes after historical evidence recovery

### A — DISTINCT_FRAMEWORK

**Current evidence:** weak / not established by casebook.

A separate framework-scale object cannot be justified by semantic uniqueness or superior decision discovery on this evidence.

It remains possible if broader integration, portability, tooling, non-AI use or future comparative evidence earns framework-scale maintenance.

### B — SPECIALISED_PROFILE / ACCOUNTABILITY OVERLAY

**Current evidence:** strengthened.

This is the closest fit to the recurring observed signal:

```text
competent domain analysis
    + bounded TRACE accountability overlay
    -> expose boundary / route / burden / residue / authority / commitment
```

Still unvalidated and model-dependent.

### C — INTEROPERABLE CONTRIBUTION

**Current evidence:** newly plausible after FPF crosswalk; not tested.

The casebook does not answer whether the useful insert should live independently, map into a broader framework, or be contributed elsewhere.

### D — THINNER MAINTAINED PRODUCT

**Current evidence:** strongly strengthened.

The casebook explicitly says the next useful object was a shorter accountable-review insert and that the bounded profile was probably too large for routine use.

### E — PRESERVATION WITHOUT EXPANSION

**Current evidence:** remains admissible.

If a thinner overlay fails to show practical value over competent review / broader methods, preserving v0.2.7 plus the research history and stopping formal expansion is consistent with the project purpose.

No outcome is selected here.

## 8. Frontier now

The most informative next test is **not** another semantic feature search and not another synthetic case by momentum.

It is to discriminate B/D/E:

```text
B: specialised overlay adds repeatable answerability value
D: only a much thinner insert earns its cost
E: competent review / broader frameworks already do enough; preserve TRACE, stop expansion
```

The correct measurement pair is:

```text
CONSEQUENTIAL OMISSIONS AVOIDED
versus
TOTAL ACTIVATION / READING / POPULATION / OVERFIRE BURDEN
```

A change in the main recommendation is neither required nor sufficient. A useful result may instead be a materially better commitment, correction route, evidence-preservation move, explicit unresolved debt, or prevention of false closure.

But if those gains do not survive competent controls and masked/human-grounded comparison, TRACE should not be protected by conceptual elegance.
