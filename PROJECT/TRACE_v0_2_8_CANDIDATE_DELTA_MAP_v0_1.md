## 0.3.0 candidates — not admitted by 0.2.8

These require a larger architecture decision and should not be smuggled into a narrow repair:

1. **Terminology/schema migration:** decide whether `structural awareness` should become `structural differentiation`, including migration of `awareness_comparison` serialization and invariants.
2. **Receiver contract:** explicit parse/orient/instantiate/transfer/contest conformance levels.
3. **Semantic conformance suite:** checker/reference tests beyond JSON shape and vocabulary, while preserving world-validity limits.
4. **Modular carrier architecture:** TRACE CORE + RECEIVER CONTRACT + PROFILES + TRANSFER CORPUS, if a single-file carrier proves suboptimal.
5. **Cross-domain test corpus:** frozen non-AI and AI cases for transfer, contest, target-set, clock, route, burden, residue and brake tests.
6. **Adversarial self-application:** require a receiver to detect a superficially TRACE-conformant but captured/theatrical packet.
