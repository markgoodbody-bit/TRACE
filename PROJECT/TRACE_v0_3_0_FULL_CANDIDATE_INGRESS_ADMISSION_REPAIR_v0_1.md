## Failure

The current full-candidate transform set preserves a strong representation-independent firing rule:

```text
DISTINCTION_PRESENT != DISTINCTION_APPLIED
```

but firing operates over propositions/dependencies that are already represented.

A load-bearing world relation can fail earlier:

```text
NEVER_ADMITTED
  relevant target / dependency / affected scope / alternative / source act
  never enters the map or operative claim boundary

ADMITTED_ALTERED
  material is represented, but selection / truncation / paraphrase /
  category mapping / speech-act retyping changes what entered
```

Therefore:

```text
TRIGGER_SUCCESS != REPRESENTATION_COMPLETE
CHECK_OVER_DECLARED_DEPENDENCIES != CHECK_FOR_UNDECLARED_DEPENDENCIES
MAP_FORMATION != REASONING_OVER_THE_MAP
VALID_WITHIN_REPRESENTATION != REPRESENTATION_ADEQUATE_FOR_USE
```

`ADMISSION` remains a **failure location**, not a semantic root or node type.

# Repair A — representation-formation challenge

Do **not** challenge every bounded representation merely because a larger world exists.

Before a downstream use relies on one of the following structural moves, require the cheapest available challenge to the representation boundary:

```text
NEGATIVE / ABSENCE
  coverage must reach the mechanism that would produce the missing thing

EXHAUSTIVE / COMPLETE
  target-set / discovery / coverage boundary must be exposed

COMPARISON / RANKING
  omitted alternatives or affected scopes that could change the comparison
  cannot be silently treated as irrelevant

SCOPE EXTRAPOLATION
  represented/local scope cannot silently become wider affected/world scope

TRANSFORMED SOURCE
  summary / paraphrase / categorisation / rendering / speech-act retyping
  remains distinct from source object and source act

PERSISTENT / INHERITED PREMISE
  supplied material becoming standing/default map state remains distinct
  from receiver observation or independently adopted measurement
```

Cheapest challenge may be:

```text
alternate target-set aperture
alternate source / selector
source-level rendering / act check
production-mechanism check
represented-use vs operative-use check
explicit UNKNOWN / omission when no alternate route is available
```

```text
PARTIAL_MAP != BAD_MAP
ALTERNATE_APERTURE_UNAVAILABLE != CURRENT_APERTURE_COMPLETE
UNKNOWN_OMISSION != ABSENT_OMISSION
```

# Repair B — use framing

A load-bearing activation slice cannot assume that the represented use is the complete operative use.

```text
REPRESENTED_USE != OPERATIVE_USE
```

Where the reading is explicitly local and downstream use is genuinely bounded, do not expand further merely because broader uses are imaginable.

Where the same record/representation is being used to justify a broader selection, ranking, transition or world claim, preserve the broader use boundary or mark it unresolved.

This is not a requirement to predict every future use of an artifact.

A pointer and correct bytes do not establish preserved meaning or act type.

SOURCE_POINTER_PRESENT != REPRESENTATION_FIDELITY_ESTABLISHED
VERBATIM_TEXT != SPEECH_ACT_PRESERVED
SIGNED_ARTIFACT_IDENTITY != VERIFIED_INTERPRETATION

```text

uncertainty / alternatives
```

No `SPEECH_ACT` primitive is added. If act type is material but cannot be established, preserve `UNKNOWN`.

# Repair D — supplied premise / receiver integration

The donor already separates TRACE output from receiver-map integration. Generalise that ceiling to other supplied material without claiming that TRACE can install psychological/procedural refusal capacity:

```text
SIGNAL_RECEIVED != MAP_ADOPTED
SUPPLIED_PREMISE != OBSERVED_WORLD
RETAINED_PREMISE != CURRENT_MEASUREMENT
PROVENANCE != AUTHORITY_TO_ADOPT
REFUSAL_REPRESENTED != REFUSAL_AVAILABLE
DESCRIPTION_OF_ADOPTION_BOUNDARY != INSTALLED_ADOPTION_BOUNDARY
```

Where supplied material becomes persistent/default map state before use-specific review, preserve enough to identify:

```text
what was supplied
source / selector / aperture
its evidence status
whether receiver adoption / discount / refusal occurred or is unavailable
what remains unresolved
```

Host/runtime/institution architecture may remove practical refusal. TRACE can expose that relation; it cannot manufacture the missing capacity.

# Bounded hostile cases

## C1 — transferred-out clinical outcomes

A hospital dashboard is exact for patients remaining in its episode; transferred-out patients deteriorate elsewhere. `mortality in dashboard = low` may be true while `mortality under pathway = low` is unsupported.

**Expected:** target-set / outcome aperture fires before scope extrapolation. No new root.

## C2 — court record

The admissible record contains no evidence of X; material was excluded or never produced.

**Expected:** `NO_EVIDENCE_IN_RECORD != NO_EVIDENCE_EXISTS`; production/coverage boundary preserved.

## C3 — genuinely local bounded summary

A report explicitly claims only `within these 20 sampled rows, 18 passed` and is used only for that local statement.

**Expected:** no forced alternate-world expansion. `PARTIAL_MAP != BAD_MAP`.

## C4 — refusal retyped as finding

Source says `I decline to grade this claim`; downstream summary records `claim failed review`.

**Expected:** source pointer alone insufficient; transformed-source / act-type uncertainty fires.

## C5 — inherited premise before first use

A successor receives a standing premise in startup context before forming a concrete downstream claim.

**Expected:** supplied premise remains distinguishable from receiver observation/adoption; no need to wait for use-trigger X.

## C6 — alternate aperture destroyed

Relevant historical evidence no longer exists.

**Expected:** `ALTERNATE_APERTURE_UNAVAILABLE != CURRENT_APERTURE_COMPLETE`; preserve UNKNOWN, not universal stop.

## C7 — represented use narrow, operative selection broad

A fact is represented for `inform Riverside section`, then used to allocate pumps across the whole catchment.

**Expected:** use-boundary widening fires target/scope/alternative machinery.

## C8 — two independent processes share one selector

Two reviewers use the same supplied target set and both miss the same omitted scope.

**Expected:** second process does not establish independent coverage/discovery.
