## 0. Observed execution boundary

The primary A/T study reached a technically executable but operationally poor transport path.

Campfire Relay v0.18.33 was restored locally and a zero-spend status preflight showed the available candidate receiver targets as `MANUAL ONLY`. The primary cold set was frozen as Google/Gemini, Alibaba/Qwen and Moonshot/Kimi, excluding OpenAI/Anthropic because Framework/CC materially participated in v0.3 construction.

Campfire Relay's manual-prompt wrapper adds delivery-receipt / identity material around the exact frozen study input. Because the frozen protocol defines exact receiver-visible A/T envelopes and uses their bytes in the primary burden measure, that wrapper was not silently substituted into the primary study.

An exact-input local runner was then prepared. It would have required the human operator to act repeatedly as cross-service transport and capture layer across 24 A/T pairs / 48 model interactions.

The operator rejected that workflow because it was confusing and required too much manual involvement.

Preserve this as a study-execution finding:

```text
TECHNICALLY_EXECUTABLE != OPERATIONALLY_USABLE
AUTOMATION_AROUND_MANUAL_TRANSPORT != LOW_OPERATOR_BURDEN
HUMAN_AS_TRANSPORT_LAYER != EXTERNAL_RECEIVER_AUTOMATION
EXPERIMENTAL_RIGOUR != PERMISSION_TO_EXPORT_COORDINATION_COST_TO_OPERATOR
```

```text
HOLD_EXTERNAL_TRANSPORT
```


## 2. What would clear the HOLD

Prefer a path that removes repeated human copy/paste/capture work while preserving the frozen comparison mechanics.

A clearing path should provide, for at least two genuinely cold receiver families and preferably three:

1. exact receiver-visible A/T prompt bytes;
2. fresh separate contexts / no cross-arm exposure;
3. same runtime identity within each pair;
4. raw-return preservation;
5. deterministic order / attempt ledger;
6. no selective retry;
7. usable output/time/token/cost metadata where available;
8. materially lower human coordination burden than the rejected 48-interaction workflow.

Possible future lanes include direct provider APIs, a connector/runtime capable of exact unwrapped prompt dispatch, or another auditable automation route.

Do not weaken the frozen protocol merely to make a convenient transport count as equivalent. If a different transport changes the receiver-visible envelope materially, either prove equivalence under the protocol or define a new study object rather than silently substituting it.

## 3. Operator-burden evidence

The execution path itself has now produced useful design evidence:

```text
MORE_AUTOMATION_CODE != LESS_HUMAN_WORK
LOCAL_LEDGERING != END_TO_END_AUTOMATION
OPERATOR_FRICTION CAN INVALIDATE PRACTICAL EXECUTION BEFORE MODEL EFFICACY IS TESTED
```

This is relevant to TRACE's broader outward-use problem: a method that requires disciplined provenance but pushes that discipline onto a human through repetitive clerical work may fail transfer even if the semantic machinery is sound.

Treat this as an execution/interface finding, not a universal TRACE primitive.

Meanwhile proceed on project work that does not require the human operator to service the experiment manually. Do not create new protocol versions, resample cases, rewrite frozen packets, or manufacture coldness from Framework/CC.
