## Purpose

Test whether the operator transfers outside AI/context-window cases and whether locating a path failure changes the repair.

## Transfer set

### Medicine — inherited handover

A prior-team description is true when written but later used as current state.

```text
representation/integration relation lost -> preserve source/time/reassessment relation
relation present but dormant at current use -> activate freshness/source distinction
current check cannot discriminate relevant alternative -> change evidential route/instrument
```

The three failures require different repairs. No clinical primitive is required.

### Law — discovery target set

A collection query misses an alias used by one custodian.

```text
alias class absent from target aperture -> change/reacquire target/search aperture
limitation documented but negative completeness claim ignores it -> activate coverage distinction
verification reruns same blind matcher -> change matcher/coverage dependency
```

`SECOND_PROCESS != INDEPENDENT_CHECK` when the failure-producing selector is shared.

### Science — selected corpus and null test

A literature search misses a terminology family; later a null experiment is under-resolved.

```text
corpus omission -> perturb literature aperture
corpus limitation present but `no effect` claim suppresses it -> narrow/qualify downstream claim
precommitted test lacks resolution -> change instrument or proposition
```

This strongly separates representation/coverage from check adequacy.

### Organisation — KPI dashboard

A dashboard excludes short repeated outages and reports `reliability improved`.

```text
threshold/omitted class absent from report -> expose target-set/measure boundary
threshold visible but headline generalised -> activate scope/measure distinction
independent team reproduces same dashboard from same selected logs -> verify world proposition/evidence root, not artifact arithmetic only
```

`REPRODUCED_ARTIFACT != VERIFIED_WORLD_PROPOSITION`.

### Education — true but selected curriculum

A curriculum contains no false statements but represents one institutional perspective.

```text
selection basis/omitted perspectives absent -> preserve bounded source aperture
selection boundary present but mastery claim treats corpus as complete dispute -> activate scope/coverage
nominally different sources all derive from one upstream summary -> expose dependency root
```

The operator can stay structural only if it does not choose which historical interpretation ought to win.

### Archive — decoder error hardens into record

An intact UTF-8 source is decoded through a legacy code page.

```text
rendering stored as source -> reacquire/preserve source-object relation
warning present but ignored during correction -> activate rendering/source distinction
second read uses same decoder -> alter observation/instrument path
```

This case also breaks a one-way stage model: a failed check/correction can publish a new artifact which becomes later world input.

## Cross-case findings

The transfer set produced four useful constraints:

1. **Failure location can change repair.** That is the main reason a bounded dependency-path diagnosis may be useful.
2. **There is no universal I->X->C pipeline.** Correction/check output can become new ingress.
3. **Observed failure location is aperture-relative.** It is not a blame or unique-cause label.
4. **Representation-route and receiver-integration failures can differ in repair, but existing TRACE already has machinery for both; no new roots are earned.**

```text
I_THEN_X_THEN_C != UNIVERSAL_EXECUTION_ORDER
FAILURE_AT_CHECK_CAN_CREATE_NEW_INGRESS
OBSERVED_FAILURE_LOCATION != UNIQUE_CAUSAL_ORIGIN
DIAGNOSTIC_LOCATION != BLAME
```

## Self-attack after transfer

The transfer did not solve invocation.

A correct dependency-path operator can remain dormant exactly as the earlier trigger surface remained dormant.

```text
OPERATOR_DEFINED != OPERATOR_INVOKED
```

The current candidate therefore refuses to claim a universal trigger. Profiles may bind invocation to executable transition surfaces; where that is impossible, dependence on aperture discipline remains visible.

The transfer also exposed that declared downstream-use scope is itself aperture-bearing. The current candidate reuses existing target/aperture machinery rather than inventing an `OPERATIVE_USE` primitive.
