```text

```

After direct attacks on B, A and D, the current working map is:


```text

```

This is a compression result, not validation. No v0.5 is earned by compression alone.

# 1. ROOT A — DISTINCT EPISTEMIC-TRANSITION / WARRANT ROOT

A does not collapse into C.

## 1.1 Decisive counterexample: false upgrade when no verification exists

Hold C fixed at:

```text
NO CHECKER
NO CHECK PATH
NO VERIFICATION PROCESS
NO CHECK EVENT
```

Then let a representation publish/expose a claim and label it checked anyway:

```text
EXPOSED -> CHECKED
```

C has no defective process because C does not exist. The defect is the unsupported epistemic transition.

```text
NO_VERIFICATION_PROCESS
+
STATUS_UPGRADED_TO_CHECKED
=
EPISTEMIC_TRANSITION_FAILURE
```

Therefore:

```text
ROOT_A != ROOT_C
```

## 1.2 Legitimate transition without verification

Provenance inspection may reveal that a selector authored or controlled the only evidence:

```text
DEPENDENCE_UNSEEN -> DEPENDENCE_EXPOSED
```

without any falsifier running and without making the proposition more verified.

## 1.3 Split between A and C

```text
C = what verification process existed / happened
A = what epistemic transition that represented history licenses
```

Useful guards:

```text
EXPOSED != CHECKABLE
CHECKABLE != CHECKED
CHECKED != SURVIVED
SURVIVED != TRUE
PAST_SURVIVAL != CURRENT_SURVIVAL
CHECK_FAILED_TO_FALSIFY != CLAIM_PROVEN
PROCESS_CORRECT != STATUS_LABEL_CORRECT
STATUS_LABEL_CONSERVATIVE != PROCESS_ADEQUATE
```

A compact status view may be derived/reconstructible from ordinary graph/history. That does not erase the distinct failure surface.

```text
ROOT != PRIMITIVE
DERIVED_STATUS != NEW_EVIDENCE
```

# 2. ROOT B — DERIVED DEPENDENCY DIAGNOSTIC

Party count and organisational separation are weak proxies for evidential independence.

Preserve:

```text
SEPARATE_PARTY != INDEPENDENT_EVIDENCE
PREFERENCE_BLIND_CHECK != INDEPENDENT_EVIDENCE_SOURCE
PRECOMMITTED != EXTERNALLY_SOURCED
DIFFERENT_OBSERVATION_TIME != DIFFERENT_CONTROL_ROOT
NO_KNOWN_DEPENDENCY_PATH != INDEPENDENT
NO_OBSERVED_DEPENDENCY != INDEPENDENCE_ESTABLISHED
```

Existing TRACE structure can represent operators, carriers, instruments and shared dependency/control roots with ordinary nodes plus `DEPENDS_ON`, `CONTROLS`, provenance and claim structure.

Current disposition:

```text
ROOT_B -> DERIVED CLAIM/USE-SCOPED DEPENDENCY DIAGNOSTIC
```

At minimum:

```text
DEPENDENCY_OBSERVED
DEPENDENCY_NOT_OBSERVED
INDEPENDENCE_NOT_ESTABLISHED
```

Question form:

```text
independent of what dependency,
for which proposition q,
for which use U,
over which causal path,
and from what time?
```

No universal independence primitive is earned.

# 4. ROOT D ATTACK — THE BUNDLE DOES NOT SURVIVE

v0.1 grouped:

```text
F7 load-bearing trigger
F8 role conflation
F9 target-scope aperture
```

under one root:

```text
trigger / role / scope propagation
```

That grouping is by a shared sentence (`must travel with the downstream claim`), not a shared failure mechanism.

## 4.1 F7 -> X_ACTIVATION, a cross-cutting firing discipline

A distinction can exist correctly in the grammar and still fail to affect the place where it matters.

```text
DISTINCTION_PRESENT != DISTINCTION_APPLIED
TRIGGER_PRESENT != TRIGGER_FIRED
```

This is not correction-window content. It appears wherever a represented distinction must become operative.

Existing TRACE already has event relations such as:

```text
ACTIVATES
FAILS_TO_ACTIVATE
```

A later trigger rule may be derived/profile-level, but its execution must be visible.

Simple endpoint perturbation is insufficient because adaptive/path-dependent systems can compensate:

```text
SAME_ENDPOINT != SAME_CAUSAL_DEPENDENCE
COMPENSATED_COUNTERFACTUAL != NON_LOAD_BEARING
```

So F7 becomes a cross-cutting activation problem, not a D semantic root.

## 4.2 F8 -> relation topology, mostly B-derived

Roles such as:

```text
selector
declarer
beneficiary
controller
evidence producer
evidence custodian
verifier
affected scope
using aperture
```

matter only where the distinction changes a downstream relation or claim.

Deletion rule:

```text
if changing only the role label changes no
  dependency,
  control,
  authority,
  evidence/provenance,
  burden,
  scope,
  route,
  or downstream inference,
then the role distinction is not load-bearing for this use.
```

Where it does change one of those, represent the actual relation rather than treating the English role name as the mechanism.

```text
ROLE_LABEL != CAUSAL_RELATION
ROLE_COUNT != INDEPENDENCE
```

This sends most of F8 into B-derived dependency/control analysis plus ordinary TRACE relations.

An external normative/policy layer may care about a role label directly. That makes the role a load-bearing supplied claim for that use; it does not create a correction-window root.

## 4.3 F9 -> C + existing aperture/coverage/route discipline

A target may repair represented scope `l1` while omitted `l2` remains affected, or a public correction may fail to reach the affected scope.

These are already expressible as:

```text
selection / target-set aperture
coverage basis
known omissions / alternatives
exact proposition/scope
access / return route
```

Preserve:

```text
TARGET_LINK_FOR_SELECTED_SCOPE != COMPLETE_AFFECTED_SCOPE
PUBLIC_CORRECTION_EXISTS != CORRECTION_REACHES_AFFECTED_SCOPE
```

The overgeneralisation from selected scope to complete affected scope is jointly constrained by:
- C: what scope/coverage/route was actually checked/reached;
- A: what stronger scope status the evidence licenses.

No distinct D root is required by F9 so far.

# 5. ADMISSION / APERTURE ENTRY — FAILURE LOCATION, NOT NEW ROOT

A deeper break occurs before trigger/role/scope propagation.

```text
OBJECT_NOT_IN_MODEL != TRIGGER_NOT_FIRED
SCOPE_NOT_REPRESENTED != SCOPE_QUALIFIER_DROPPED
CLAIM_OMITTED != CLAIM_LABELLED_NON_LOAD_BEARING
```

Worked form:

```text
An allocation system reasons correctly over every household in registry R.
Every represented load-bearing claim fires.
Roles and scope qualifiers are correct.

But one materially affected household h is absent from R,
and the proposition "R contains the materially affected households"
never enters the claim set.
```

No trigger failed on `h`; `h` was never admitted.

A counterfactual trigger over represented claims cannot vary a claim that is absent.

Existing TRACE aperture/target-set machinery can represent the selection boundary. Therefore admission is a load-bearing **location** that must be inspected when downstream output depends on treating a represented set as sufficient.

Kimi's independent extension usefully separates two modes:

```text
ADMISSION-OMISSION
  object never admitted
  -> target-set / coverage / aperture discipline

ADMISSION-ALTERATION
  object admitted but transformed at intake
  -> source/provenance fidelity and re-execution discipline
```

Preserve:

```text
ADMITTED != TRANSCRIBED_FAITHFULLY
EDGE_PRESENT != EDGE_FAITHFUL
LOCATION != ROOT
```

The two modes need different checks but do not currently earn a fifth correction-window primitive or semantic root.
