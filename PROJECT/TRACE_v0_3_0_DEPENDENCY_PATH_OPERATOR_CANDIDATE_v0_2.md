## 0. What survived compression

Do not promote `INGRESS`, `ACTIVATION`, `CHECK`, `R`, `J`, `X`, `C`, `TRIGGER`, `MATERIALITY`, or `REFUSAL` into semantic primitives.

The current surviving operator is one bounded walk over existing TRACE structure:

> **For a declared downstream use or transition, walk backward through the represented dependencies and representation paths that supply it. Preserve only distinctions whose collapse can change the use under the represented model. Where the use relies on a check, walk that check forward through proposition, evidence aperture, instrument, dependencies, timing and return. Stop branchwise when further traversal cannot change the declared use; preserve specific unresolved omissions rather than treating the represented map as complete.**

The operator diagnoses structure. It does not guarantee that anyone invokes it.

---

# 1. USE SCOPE IS ITSELF APERTURE-BOUND

A single declared `U` can be narrower than the transition actually being selected, justified, routed or inherited.

Do not solve that with a new `OPERATIVE_USE` primitive.

Where use-scope completeness is load-bearing, reuse existing target/aperture machinery to represent:

```text
source of declared use / transition scope
represented downstream uses
selection basis
known omitted use classes
alternative use-scope apertures
bounds / disputes
```

Preserve:

```text
DECLARED_USE != EXHAUSTIVE_USE
REPRESENTED_USE != OPERATIVE_USE
NOT_REPRESENTED_AS_USE != NO_DOWNSTREAM_EFFECT
USE_SCOPE_DECLARED != USE_SCOPE_COMPLETE
```

A broader fork is kept open only when a **specific alternate use/transition** can be named that changes the traversed dependency set.

```text
GENERIC_POSSIBLE_BROADER_USE != MATERIAL_UNRESOLVED_USE_FORK
```

This keeps use-selection visible without forcing inspection of every imaginable future use.

# 2. BACKWARD DEPENDENCY / REPRESENTATION WALK

For each represented dependency feeding the selected downstream use or transition:

```text
USE / TRANSITION
<- claim / condition / route / comparison input
<- standing map / retained relation
<- supplied record / claim / signal
<- target / rendering / paraphrase / representation path where material
<- bounded source / world-facing aperture where available
```

At each relation:

```text
IF collapsing an existing TRACE distinction can change the status or
interpretation of the declared use under the represented model,
THEN keep that distinction active on this branch.
```

If a specific unresolved alternative would change the use, preserve the fork.

If not, stop that branch.

Existing machinery carries the path:

```text
APERTURE
MAP
CLAIM / EVIDENCE
PROVENANCE
SOURCE / ROUTE
TARGET-SET
BOUNDS / OMITS / DISPUTES
RETAINED HISTORY
receiver-specific integration where instantiated
```

No new representation object is required.

# 3. FORWARD CHECK WALK

When a downstream use relies on a check, audit, matcher, verification or correction process, inspect the check as a causal route:

```text
exact proposition / alternative to discriminate
-> evidence / target aperture
-> instrument or matcher capability / resolution
-> evidence / control / adaptivity dependencies
-> answer-information / precommitment state
-> execution
-> completion clock
-> result route
-> return to using aperture
```

Preserve at least the established non-entailments where they are load-bearing:

```text
CHECK_PATH_EXISTS != CHECK_EXECUTED
CHECK_EXECUTED != CHECK_WAS_ADEQUATE
CHECKED_EVIDENCE != CHECKED_LOAD_BEARING_PROPOSITION
PROCEDURE_PRECOMMITTED != INSTRUMENT_ADEQUATE
TEST_RAN != RELEVANT_ALTERNATIVE_DETECTABLE
CHECK_COMPLETED != CHECK_RESULT_REACHED_USE
EVENTUALLY_CHECKABLE != CHECKABLE_BEFORE_USE
CHECKER_SEPARATE != EVIDENCE_DEPENDENCY_SEPARATE
```

Check output can become a new record or world input. The walk is therefore recursive rather than a one-way I->X->C pipeline.

# 4. INVOCATION CEILING — THE OPERATOR CAN ALSO REMAIN DORMANT

The old trigger-surface work failed because a correct trigger can itself fail to fire.

This operator does not escape that problem merely by being smaller.

```text
OPERATOR_DEFINED != OPERATOR_INVOKED
OPERATOR_AVAILABLE != OPERATOR_USED
DISTINCTION_RECOVERABLE != DISTINCTION_APPLIED
```

TRACE core does not possess a universal world-valid rule for when every receiver must invoke the walk.

Where a domain profile has an executable transition boundary, it may bind invocation mechanically to that boundary. Examples include a declared publish transition, a negative-completeness assertion, a capability use, a high-reach authority transition, or another domain-specific event.

But:

```text
PROFILE_BOUND_TRIGGER != UNIVERSAL_TRACE_TRIGGER
MACHINE_CHECK_AVAILABLE != MACHINE_CHECK_RAN
```

Where no executable invocation surface exists, the remaining dependency on aperture discipline must be explicit rather than disguised as machinery.

```text
UNEXECUTABLE_OPERATOR != INSTALLED_GUARD
```

This is a ceiling on the candidate, not a reason to create a universal trigger primitive.

# 5. PRE-CLAIM / PRE-USE INGRESS

Some supplied material helps constitute standing map or retained history before a later explicit claim exists.

The operator can inspect such a case only if the receiving architecture exposes the relevant **integration / retention transition** as a declared transition surface.

Then that transition itself can be the local downstream use for the bounded walk.

```text
SUPPLIED_MATERIAL -> RETAIN / INTEGRATE TRANSITION
```

This does **not** mean every received proposition must be audited before memory or learning.

It means:

```text
IF an architecture already exposes a consequential integration transition,
TRACE can apply the same dependency-path discipline there.
```

Ceilings:

```text
RECEPTION != ADOPTION
TRACE_OUTPUT != RECEIVER_MAP_UPDATE
INHERITED != FALSE
INHERITED != UNUSABLE
ADOPTION != VALIDATION
CONCEPTUAL_REFUSAL != PRACTICAL_REFUSAL_ROUTE
```

If the architecture provides no observable integration boundary, TRACE can describe the limitation but cannot install one by description.

# 7. STOPPING RULE

Stop each branch when one of the following holds:

```text
A. collapsing the next available represented distinction cannot change the declared use under the represented model;
B. a declared source/aperture boundary is reached and further world access is unavailable;
C. a specific unresolved omission/use fork is preserved and no available bounded route can reduce it before use;
D. further checking cannot change the available status before the relevant hardening/use clock;
E. further depth lies outside the declared profile/use boundary and no specific omitted dependency at that depth has been shown capable of changing the use.
```

Stopping never upgrades the world claim:

```text
WALK_STOPPED != WORLD_COMPLETE
BOUNDED_READING != COMPLETE_WORLD_MODEL
NO_AVAILABLE_FURTHER_CHECK != CLAIM_TRUE
```

# 8. TRANSFER RESULT

The six-domain transfer matrix — medicine, law, science, organisations, education and archives — found that representation/integration, dormant distinction and check-route failures can demand different repairs.

It also found:

```text
I_THEN_X_THEN_C != UNIVERSAL_EXECUTION_ORDER
FAILURE_AT_CHECK_CAN_CREATE_NEW_INGRESS
OBSERVED_FAILURE_LOCATION != UNIQUE_CAUSAL_ORIGIN
```

So named stages were demoted and the single recursive walk survived provisionally.

The transfer evidence does not validate the operator. It only shows that the current distinction is not AI/context-window specific.

# 9. FALSIFICATION TARGETS

Hold or delete the operator if hostile use shows:

1. branchwise walking still expands routine uses toward the whole TRACE packet;
2. use-scope apertures merely relocate the self-declared-materiality problem;
3. a malicious/narrow use declaration hides a consequential transition without any specific alternate-use fork being recoverable;
4. representation-path provenance creates infinite provenance-of-provenance recursion;
5. check inspection creates infinite checking-of-checks;
6. pre-use integration handling becomes a universal memory/learning bureaucracy;
7. an executable profile trigger is mistaken for a universal TRACE requirement;
8. an unexecutable operator is spoken of as an installed guard;
9. stopping closes a branch that later proves load-bearing under information available at the time;
10. ordinary TRACE already derives the same bounded walk reliably enough that this object adds no corrective work;
11. `consequential`, `material`, `affected`, or use-scope selection imports a hidden moral/value selector;
12. locating the failure does not change the available repair route.

One counterexample is enough to hold integration.
