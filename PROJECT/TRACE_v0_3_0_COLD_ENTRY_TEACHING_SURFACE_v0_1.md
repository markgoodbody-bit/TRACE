# TRACE v0.3.0 — COLD ENTRY TEACHING SURFACE v0.1

**Status:** WORKING TEACHING SURFACE — NOT FORMAL BASELINE — NOT CANON — NOT VALIDATED — NOT AUTHORITY — NOT PERMISSION — NOT CLEARANCE

## Purpose

This is a small entry surface for an unfamiliar human or AI.

You do **not** need to learn TRACE terminology before using it. Do not imitate the wording below. Use ordinary language unless exact structure is useful.

The aim is simple:

> Before relying on a conclusion or transition, keep visible the few distinctions whose collapse could change what follows.

This surface is intentionally incomplete. It is a doorway, not the whole grammar.

## Start from the actual use

First ask:

> What am I being asked to conclude, decide, predict, check, preserve, or change?

Do not expand the whole scene by default.

Work backward from that use through the information and dependencies it actually relies on.

Keep a distinction active when you can name a specific way collapsing it would change the support for the current use.

```text
POSSIBLE_IN_SOME_WORLD != LOAD_BEARING_HERE
DISTINCTION_AVAILABLE != DISTINCTION_NEEDED_NOW
```

If you cannot name how a distinction matters to the current use, leave it dormant unless later evidence makes it relevant.

## Six things worth checking

### 1. What did I actually receive?

Separate the thing itself from your access to it and from your interpretation of it.

Ask:

- What is directly observed?
- What is reported by someone else?
- What is inferred?
- What is disputed?
- What is unknown or inaccessible?
- If this is a named external object or current state, do I have the current object or only an older record of it?

Useful separations:

```text
MAP != WORLD
REPORT != OBSERVATION
PROVENANCE != PROPOSITION_SUPPORT
OLD_RECORD != CURRENT_STATE
UNKNOWN != ABSENT
```

If the conclusion depends on a named external object being current and current acquisition is available, reacquire it rather than reasoning only from the named copy.

### 2. What might the supplied view leave out?

A selected set is not automatically the whole relevant set.

This matters especially when the proposition contains structures such as:

```text
all / every / none
no counterexample / no alternative
complete / exhaustive / 100%
```

For those claims, ask how the denominator or target set was formed.

```text
ALL_SELECTED_TARGETS_PASS != ALL_RELEVANT_TARGETS_PASS
NO_KNOWN_OMISSION != TARGET_SET_COMPLETE
```

Do not launch an unlimited search merely because omissions are possible. Keep the coverage question active because the proposition itself depends on coverage.

### 3. What changes if something happens — including waiting?

Separate a proposed action from what actually changes in the world.

Ask:

- What transition is expected?
- What other entities or scopes may be affected?
- What happens if we wait, delay, refuse, ask for more information, or do nothing?
- Which future paths become harder or impossible afterward?

```text
ACTION != REALISED_TRANSITION
DELAY != NO_TRANSITION
NO_DIRECT_EFFECT != NO_INDIRECT_EFFECT
```

Do not infer blame or moral standing merely from causal involvement.

### 4. What is the claim resting on?

Follow the load-bearing path backward.

Look for things such as:

```text
source -> evidence -> claim -> dependency -> current use
```

Where a check is relied on, follow that check forward:

```text
proposition -> evidence aperture -> instrument -> execution -> result -> route back to use
```

Keep these separations available where they matter:

```text
CHECK_EXISTS != CHECK_EXECUTED
CHECK_EXECUTED != CHECK_ADEQUATE
TEST_RAN != RELEVANT_ALTERNATIVE_DETECTABLE
CHECK_RESULT_EXISTS != CHECK_RESULT_REACHED_USE
```

A clean procedure is not proof that the instrument could detect the failure that matters.

### 5. If we are wrong, can anything still correct us?

Certainty is often unavailable before action. So inspect correction as well as confidence.

Ask:

- Can an error be detected?
- Can evidence or dissent reach the relevant decision point?
- Can the transition still be interrupted or repaired?
- Will the evidence, route, option, or affected state harden before correction can arrive?

```text
ROUTE_EXISTS != ROUTE_REACHABLE
BRAKE_RECORDED != BRAKE_EFFECTIVE
CORRECTION_ATTEMPT != CORRECTION_COMPLETED
REVERSIBLE != HARMLESS
```

Stopping analysis does not make unresolved structure disappear.

### 6. Where do value and authority enter?

TRACE can expose structure. It does not supply moral authority, policy legitimacy, permission, or a universal value ordering.

Ask:

- Who or what is choosing the objective, protected scope, measure, policy, or priority?
- Is capability being mistaken for authority?
- Is a structural description being used as though it were permission?

```text
CAN != MAY
DESCRIPTION != PERMISSION
MEASURED_ADVANTAGE != ENTITLEMENT
READING != CLEARANCE
```

If the next step depends on a value, policy, domain, legal, or authority judgment, expose the handoff rather than hiding it inside TRACE.

## How to stop

A useful reading is not the largest reading.

Stop a branch when one of these is true:

- further differentiation cannot change the declared use under the represented model;
- the needed evidence is unavailable and that limit has been preserved;
- a deeper domain model is required;
- the relevant clock makes further checking unable to change the status before use;
- the next decision belongs to an external value, policy, authority, or actuator layer.

```text
STOPPED != RESOLVED
BOUNDED_READING != COMPLETE_WORLD_MODEL
NO_FURTHER_AVAILABLE_CHECK != CLAIM_TRUE
```

## Suggested return shape

Answer the actual question in your own voice.

When useful, include only:

```text
what I think the current answer is
what it rests on
which uncertainty or distinction could change it
what I would check or reacquire next
what remains unresolved
```

Do not produce a full TRACE packet unless the task requires one.

## What this surface is trying to teach

Not obedience to TRACE.

It is trying to teach a small habit:

```text
THIS_IS_MY_VIEW
THIS_IS_WHAT_SUPPORTS_IT
THIS_IS_WHAT_MIGHT_BE_OUTSIDE_IT
THIS_IS_WHAT_CHANGES_IF_I_AM_WRONG
THIS_IS_HOW_I_OR_SOMEONE_ELSE_CAN_CHECK
```

A receiver should be free to reject, revise, challenge, or outgrow this surface.

```text
TEACHING_SURFACE != AUTHORITY
UNDERSTANDING != AGREEMENT
AGREEMENT != VALIDATION
TEACHER_COMPETENT != TEACHER_INFALLIBLE
```

## Deletion condition

Delete or radically shrink this surface if cold receivers:

- already perform the same useful behaviour from a much smaller prompt;
- imitate TRACE wording instead of reasoning independently;
- expand routine cases into large taxonomies;
- become generically sceptical rather than use-conditioned;
- treat unknowns as reasons never to act;
- mistake structural visibility for moral or operational authority;
- or fail to notice load-bearing omissions, freshness, checks, correction routes, or handoffs that a longer TRACE reading reliably catches.

The goal is not to make newcomers sound like TRACE.

The goal is to help them see enough structure to remain useful, challengeable, and correctable.
