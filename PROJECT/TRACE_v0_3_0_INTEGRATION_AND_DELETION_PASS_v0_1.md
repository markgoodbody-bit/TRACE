### 3.5 Generic firing is representation-independent

```text
DISTINCTION_PRESENT != DISTINCTION_APPLIED
REPRESENTATION_TYPE != EVIDENCE_STATUS
CONFIGURATION_FIELD != WARRANT_FREE_FACT
```

This is an activation rule, not a trigger primitive.

### 3.6 Evidence state is separate from access/custody state

Recovered from v0.2.7 donor after compression made the distinction too implicit.

```text

UNAVAILABLE_TO_THIS_READER != UNIVERSALLY_UNKNOWN
AVAILABLE != AUTHORISED_TO_DISCLOSE
```

The universal spine carries only the separation; the richer access/custody algebra remains a full-candidate obligation.

### 3.7 Future-path correspondence cannot be inferred from labels

Recovered from donor-loss testing.

```text

PATH_IDENTIFIER_PERSISTS != PATH_EFFECT_PERSISTS
```

A preservation/loss/open/close comparison across states needs supported correspondence at the resolution relevant to the claim. No trajectory-matching primitive.

## 4. Correction-window integration outcome

The original serial compression remains useful only as a bounded special case.

The current universal centre is:

1. represent required correction work as event/precedence structure where overlap/branching matters;
2. include load-bearing verification/check time;
3. require an explicit represented target boundary condition and expose selector/source/basis;
4. keep route/capability-relative unattainability separate from world irreversibility;
5. require supported common temporal basis before interval comparison;
6. do not equate precedence-unordered stages with feasible concurrency;
7. guaranteed-open requires a supported feasible-completion upper bound before the boundary lower bound;
8. guarded lower-bound closure is allowed only when the supposedly required path is actually required;
9. keep multiple load-bearing boundaries separate absent justified composition;
10. rebind when load-bearing target/boundary/capability/time/process/execution assumptions change;
11. otherwise preserve `UNKNOWN`.

```text
POINT_ESTIMATE_FITS != GUARANTEED_OPEN
SAME_UNIT != SAME_REFERENCE_EVENT
NO_PRECEDENCE_EDGE != CONCURRENCY_AVAILABLE
STRUCTURAL_PARALLELISM != FEASIBLE_PARALLELISM
MULTIPLE_LOAD_BEARING_BOUNDARIES != ONE_UNQUALIFIED_CLOSE
```

No scheduler, resource, capacity, target-boundary or correction-window primitive is added.
