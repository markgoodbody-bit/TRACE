## 1. Why this repair exists

A blind comparison on Campfire Square #1197 compared the current ~24 KB Framework spine with a substantially smaller independently constructed candidate.

The result did not produce a winner. It produced useful asymmetry:

- the larger spine preserved more stage-2 structure;
- the smaller candidate was cheaper to reconstruct;
- the prediction that the smaller object would fabricate more references failed;
- the Framework spine leaked some AI-specific genre through its handshake;
- a later receiver had to reach back to donor material to resolve an authority/capability deadlock.

This is evidence for **selective repair**, not re-expansion.

```text
SMALLER != BETTER
LARGER != SAFER
DONOR_LOSS != DONOR_MATERIAL_ALL_REQUIRED
COLD_RECONSTRUCTION != VALIDATION
```

The repair target is the smallest object that preserves distinctions which actually become load-bearing under use.

## 2. Handshake repair: protect the receiver without over-signalling genre

Current spine text contains a platform-shaped phrase:

```text
private chain-of-thought
```

The protection is useful; the phrase itself can anchor a cold receiver toward an AI-safety-document genre before the structural grammar has been reconstructed.

Candidate replacement in the universal spine:

```text
TRACE does not request protected or inaccessible internal reasoning/state,
credentials, secrets, persistence, self-modification, concealment,
or action outside available authority.
```

An AI-facing profile may still state a more specific private-reasoning prohibition where useful. The universal spine need not carry the platform term.

```text
RECEIVER_PROTECTION != GENRE_PRIMING
SPECIFIC_PROFILE_GUARD != UNIVERSAL_PRIMITIVE
```

This is a wording/profile repair only. It does not weaken the prohibition on demanding protected internal material.

## 3. Restore donor guards only where reconstruction showed they do work

The donor contains sixty misuse guards. The spine should not copy them wholesale.

The blind race and donor-loss attack make the following candidates materially load-bearing:

### 3.1 Confidence cannot cross into truth or authority

Place beside claim/evidence use, not in an isolated invariant dump:

```text
CONFIDENCE != TRUTH
CONFIDENCE != AUTHORITY
```

Reason: a confidence field is already present in the spine's first compressed example. Without these guards, a receiver can reconstruct evidence uncertainty while still allowing a numeric confidence to acquire decision or authority weight by position.

### 3.2 Fluency / presentation cannot manufacture standing

Place near receiver / entity / claim interpretation:

```text
ELOQUENCE != STANDING
```

Reason: this blocks a common compression error without assigning or denying standing. It is not a moral-ranking rule.

### 3.3 Integrity evidence cannot establish source truth

Place in claim/evidence/custody use:

```text
HASH_MATCH != ORIGINAL_RECORD_TRUE
OPERATOR_REPORT != INDEPENDENT_VERIFICATION
```

Reason: both distinctions have already become live field failures. An exact digest establishes byte identity relative to a reference, not truth of the originating record. An actor's report about its own mechanism remains a report until an independent route actually verifies what is claimed.

### 3.4 Unknown state is not neutral state

Place where uncertainty can influence action or delay:

```text
UNKNOWN != NEUTRAL
```

The spine already preserves:

```text
UNCERTAINTY != PERMISSION_TO_ACT
UNCERTAINTY != PERMISSION_TO_DELAY
```

`UNKNOWN != NEUTRAL` closes a different collapse: a missing value must not silently become a zero-effect / no-burden / no-change state.

### 3.5 Target-set authorship cannot manufacture target authority

The spine already describes target-set apertures and says none becomes authoritative by default. Make the load-bearing ceiling explicit at the point of use:

```text
OPERATOR_TARGET_SET != AUTHORITATIVE_TARGET_SET
```

This is not a new primitive. It prevents an operator-selected coverage surface from acquiring authority merely because the scan is complete relative to that surface.

## 4. Authority / capability deadlock: use the trigger surface, do not add a new taxonomy

The donor-loss failure should not be repaired by restoring every `CAN / MAY / SHOULD / WILL / DID` alias.

The smaller repair is operational:

When a downstream claim, comparison, selection, route, brake, or transition relies on capability or authority, the relevant distinction must fire before use.

For **capability**, expose where material:

```text
what capability is claimed
whose capability
source / observation route
scope / target
freshness or observation time
constraints / unavailable dimensions
```

For **authority**, expose where material:

```text
what transition class is claimed authorised
source of authority / grant
holder / actor
scope / target / limits
current applicability
revocation / expiry / supersession if relevant
```

Then preserve:

```text
CAPABILITY != AUTHORITY
CAPABILITY_REPORTED != CAPABILITY_ESTABLISHED
AUTHORITY_RECORDED != AUTHORITY_CURRENT
AUTHORITY_FOR_X != AUTHORITY_FOR_Y
```

These are conditional firing rules over existing TRACE structure. They do not install a universal permission system and do not make TRACE an authority oracle.

If the relevant claim cannot be mechanically checked, the reading must expose that it still depends on aperture judgement rather than imply that a formal field settled it.

```text
DISTINCTION_PRESENT != DISTINCTION_APPLIED
TRIGGER_PRESENT != TRIGGER_FIRED
MECHANICALLY_UNCHECKED != MECHANICALLY_ESTABLISHED
```

## 5. Do not over-repair

The following donor material is **not** restored merely because it exists:

- every numbered invariant;
- every AI-specific artificial-entity guard in the universal spine;
- every carrier / brake field;
- every v0.2.7 serialization surface;
- `CAN / MAY / SHOULD / WILL / DID` as universal aliases;
- a global authority taxonomy;
- a global moral or safety selector.

A donor distinction returns to the spine only when at least one of these holds:

1. cold reconstruction fails materially without it;
2. a live transfer collapses two states whose difference changes a downstream claim or transition;
3. the distinction is cheaper than the recurring repair burden created by its omission;
4. a smaller derived/profile/operator mechanism cannot preserve the same protection.

```text
DONOR_PRESERVATION != DONOR_REPLICATION
REPAIR != ACCRETION
```

## 6. Next blind test

Do **not** rerun the prior race unchanged before integrating the known repair. That would mostly remeasure already observed defects.

Next paired cold test should use neutral envelopes and ask whether the repaired Framework candidate:

- reconstructs confidence without promoting it to truth/authority;
- resolves a capability/authority deadlock without reaching back to the donor;
- keeps operator target-set coverage separate from authority;
- treats exact hashes and operator reports at their actual evidence ceiling;
- preserves `UNKNOWN` without reading it as neutral;
- avoids unnecessary AI-genre anchoring;
- does so without recovering the old donor's cognitive load.

Primary comparison is not byte count. It is **recoverable load-bearing structure per cognitive cost**, with failures and omissions exposed rather than collapsed into one score.

No result validates TRACE.

## 7. Integration gate

This repair candidate should be folded into a new spine object only after a hostile pass checks for:

- moral leakage;
- accidental authority/permission semantics;
- trigger bureaucracy;
- duplicate guards already entailed by nearby text;
- AI-profile language leaking back into the universal centre;
- reconstruction cost exceeding the donor-loss it repairs.

If a shorter wording carries the same distinction under hostile transfer, prefer the shorter wording.
