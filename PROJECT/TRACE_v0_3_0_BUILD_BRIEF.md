## Current surviving repairs

### Representation-independent firing

A load-bearing proposition cannot bypass evidence/currentness/scope/warrant discipline merely because it appears as configuration, metadata, status, cached output, a field or prose rather than an explicit claim object.

```text
DISTINCTION_PRESENT != DISTINCTION_APPLIED
CONFIGURATION_FIELD != WARRANT_FREE_FACT
LOAD_BEARING_UNKNOWN != NOT_LOAD_BEARING
```

### Currentness

Freshness can expire through a relevant dependency change, not only age.

```text
DATE_CURRENT != DERIVED_VALUE_CURRENT
SOURCE_MUTATED != LOAD_BEARING_DEPENDENCY_CHANGED
MUTATION_OBSERVED != CLAIM_INVALIDATED
```

### Evidence / access / custody

Evidence state is independent of receiver access/custody/disclosure authority.

```text
EVIDENCE_STATE != ACCESS_CUSTODY_STATE
UNAVAILABLE_TO_THIS_READER != UNIVERSALLY_UNKNOWN
AVAILABLE != AUTHORISED_TO_DISCLOSE
```

### Verification / liveness

```text

PROCESS_EXISTS != PROCESS_HEALTHY
EXTERNAL != INDEPENDENT
```

### Correction window

Primary general object is a represented process/event precedence graph plus explicit target boundary and timing bindings. Precedence-only parallelism does not establish feasible concurrency.

```text
SAME_UNIT != SAME_REFERENCE_EVENT
NO_PRECEDENCE_EDGE != CONCURRENCY_AVAILABLE
STRUCTURAL_PARALLELISM != FEASIBLE_PARALLELISM
POINT_ESTIMATE_FITS != GUARANTEED_OPEN
```

Guaranteed-open requires a supported feasible-completion upper bound before the relevant boundary lower bound. A guarded lower-bound route may establish closed only when the supposedly required path is actually required. Otherwise preserve `UNKNOWN`.

The familiar serial inequality survives only as a bounded derived shorthand.

### Future-path correspondence

A repeated path label does not establish that the same continuation remains reachable.

```text
SAME_PATH_LABEL != SAME_TRAJECTORY
PATH_IDENTIFIER_PERSISTS != PATH_EFFECT_PERSISTS
```
