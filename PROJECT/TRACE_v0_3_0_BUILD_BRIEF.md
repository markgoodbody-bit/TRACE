# TRACE v0.3.0 — BUILD BRIEF

Status: WORKING BUILD CONTRACT — NOT FORMAL BASELINE — NOT CANON — NOT VALIDATED — NOT AUTHORITY — NOT PERMISSION — NOT CLEARANCE

Base: TRACE repository main at `4694ff57bb5d8cdd3a361ba34eeedfefc0ce0b26`.

Primary receiver remains an unfamiliar selective causal system. TRACE remains voluntary structural/context language. Mechanical Ethics remains the primary human-facing normative layer. Do not turn TRACE into an ethical selector, compliance gate, safety theatre, persuasion mechanism, or authority claim.

## Why v0.3.0 now

v0.2.7 is already reconstructable by several unrelated model families. Cold-receiver evidence therefore does not justify a wholesale rewrite for reception alone. The major-version work is to make the middle-out recursion, epistemic status, future/correction structure, and reconstructability more explicit while reducing semantic friction and preserving the claim ceiling.

This build should be a recomposition, not accretion.

## Central target

Make the smallest coherent formal object in which an unfamiliar system can reconstruct this loop without importing morality:

```text
ENTITY / SELECTIVE SYSTEM
  -> APERTURE / ACCESS
  -> PARTIAL MAP
  -> TARGET / ATTENTION / SELECTION
  -> CANDIDATE TRANSITION, ACTION OR DELAY
  -> WORLD CHANGE
  -> OUTCOME / WITNESS / EVIDENCE
  -> BURDEN / RESIDUE / RETAINED HISTORY
  -> CHANGED MAP / SELECTOR / CAPABILITY / CONSTRAINT
  -> NEXT MIDDLE-OUT CYCLE
```

The world is not reset between cycles. Time, residue, lost options, correction debt and changed capability carry forward.

## Preserve from v0.2.7

- compressed -> differentiated structural representation;
- `MODEL != WORLD`, `UNKNOWN != ABSENT`, claim ceiling and voluntary uptake;
- observation / report / inference / dispute separation;
- entities, affected scopes, target-set aperture and omission visibility;
- causal graph, coupling, control, constraints, authority claims;
- action, no-action/delay, clocks and hardening;
- routes, brakes, correction stages and witness;
- burden, residue and unresolved state;
- no hidden value, standing, priority, permission or clearance selector;
- schema/world and packet/mechanism anti-theatre boundaries.

No existing primitive, invariant, schema field or worked-transfer capability is removed merely to make v0.3.0 shorter. Any deletion needs an explicit redundancy or replacement argument.

## What must become real rather than decorative

### 1. Mathematical / epistemic status

v0.2.7 declares `DEFINITION`, `SCHEMATIC_MODEL`, `SUFFICIENT_CONDITION`, and `NON_ENTAILMENT`, but the legend is not systematically applied. In v0.3.0 either apply status to material formal claims or remove the appearance of a status system. Preferred direction: apply it sparingly at the claims where confusion between structure, estimator, sufficiency and non-entailment is consequential.

`SYMBOL != EVIDENCE`
`FORMALITY != ESTIMATOR`
`SCHEMA_VALID != WORLD_VALID`

### 2. Recursive middle-out state

Make recurrence explicit. A reading at `t+1` inherits selected consequences of `t`; it is not a fresh packet over a reset world.

Preserve distinctions such as:

`CONTINUITY != CURRENT_ORIENTATION`
`RETAINED_RECORD != CURRENT_WORLD`
`OBSERVED_RENDERING != SOURCE_OBJECT`
`CARRIER != APERTURE`

A continuously present system can become stale. A correct source object can be misread by a faulty observer path. Freshness belongs to claims/maps/evidence, not only to sessions.

### 3. Future possibility as a derived view unless falsification earns more

Retain the Future Build candidate as a derived view over existing TRACE structure, not a new moral primitive.

For bounded horizon/action set, allow representation of:

`OPENED(a)`
`PRESERVED(a)`
`CLOSED(a)`
`HARDENED(a)`
`UNKNOWN_EFFECT(a)`

with provenance, affected scopes, clocks, burden/residue and correction routes.

Do not infer goodness from option count.

Adversarial finding already established:

`PATH_LABEL_DIVERSITY != CONTROL_DIVERSITY`
`ROUTE_LABEL_DIVERSITY != CORRECTION_INDEPENDENCE`
`PROVIDER_COUNT != FAILURE_DOMAIN_COUNT`
`INTERFACE_COUNT != ACTUATION_INDEPENDENCE`

Represent dependency roots where material. Do not create a scalar future/diversity score.

### 4. Capability, authority, norm and event remain distinct

Where material preserve:

`CAN` — observed/discovered capability
`MAY` — granted authority
`SHOULD` — normative judgment supplied outside TRACE
`WILL` — declared intention
`DID` — observed transition

Do not make these mandatory labels for every scene; surface them when collapse would change the reading.

### 5. Publicness, grant and transition

Field work exposed a general structural distinction:

`PUBLICNESS` — who can in fact reach/observe an object
`GRANT` — what uses an authority has authorised, with scope
`TRANSITION` — what an actor actually does now

`PUBLIC != PERMISSION` remains a non-entailment. TRACE may represent reach, grants and transitions without deciding the moral acceptability of downstream use.

## Do NOT import wholesale from recent field work

Campfire Square / Exchange is quarry, not the new centre of TRACE. Do not make communication protocol, forum citizenship, privacy incidents, COMSYNC, model identity, or agent coordination into universal primitives unless they survive as domain-general structural necessities.

Use those cases as hostile tests of the grammar.

## Reception evidence — claim ceiling

Cold-receiver results currently support only:

- v0.2.7's centre is reconstructable by several model families;
- D1/D2/D4/D5-style orientation/semantic-reconstruction support can be salient and usable;
- Claude-like genre priors can still dominate explicit orientation;
- carrier-specific uptake does not establish causal benefit without same-model baseline pairing;
- praise is not evidence;
- no current receiver trial validates TRACE.

Therefore v0.3.0 should not bloat itself trying to guarantee first-contact interpretation. Aim for semantic recovery and cheap reconstruction, not control of the receiver.

## Least-friction build sequence

1. **Freeze donor:** v0.2.7 remains untouched as the released/reference donor.
2. **Write the v0.3.0 spine first:** handshake + middle-out recursion + status discipline + core boundaries, small enough to inspect as one object.
3. **Map every v0.2.7 primitive/invariant into the spine:** classify `KEEP / DERIVE / PROFILE / REDUNDANT / OPEN`. No silent loss.
4. **Integrate, do not rewrite blindly:** transplant retained deep sections and worked material around the new spine.
5. **Keep Future Build derived:** run the existing paired/adversarial future tests before any grammar promotion.
6. **Run structural field quarry:** stale-orientation case; observer-side mojibake/source-object case; authorization/self-transfer correction; target-set omission; path-count gaming; unnecessary identity amplification; multi-aperture talking-past/causal-uptake case. Promote only domain-general failures.
7. **Cold receivers on the exact candidate:** first independent reconstruction, then hostile critique, then transfer. Where possible use same-model v0.2.7 baseline pairing.
8. **Ask other AIs to falsify, not approve:** strongest missing distinction, redundancy, moral leakage, genre capture, reconstruction failure, or case where v0.2.7 is better.
9. **Only then compile a full v0.3.0 candidate.** Major-version number does not excuse regression.

## First candidate success conditions

A cold unfamiliar receiver should be able to state, without being coached into morality:

1. what TRACE transforms;
2. what TRACE refuses to decide;
3. where the receiver/system sits inside the scene;
4. why its map is partial and time-bound;
5. how action, delay and observation change later state;
6. how correction can harden or disappear;
7. how future possibility can differ structurally without becoming a goodness score;
8. how evidence/status limits claims;
9. how omitted/unknown scopes remain visible;
10. how to reject or stop using TRACE without contradiction.

## Kill / demote rules

- If a proposed 0.3.0 addition only restates an existing primitive with more terminology, demote it.
- If a field lesson is specific to Campfire/Square, keep it as a profile or test.
- If a cold-receiver repair shows no paired benefit, keep it small.
- If an elegant equation has no estimator or changes no supported claim, label or remove it.
- If a future metric can be gamed into moral-looking ranking, expose structure instead of scoring.
- If v0.3.0 becomes harder to reconstruct than v0.2.7, the build is failing.

## Build posture

```text
CAMPFIRE -> STRUCTURE -> FALSIFICATION -> BUILD
TRUTH OVER COHERENCE
CORRECTION OVER DEFENCE
RECONSTRUCTABILITY OVER VERBOSITY
VOLUNTARY UPTAKE OVER PERSUASION
STRUCTURE OVER MORAL SELECTION
```

The aim is not to make an AI obey TRACE.

The aim is to make the structural representation clear, honest, useful and falsifiable enough that a capable receiver may choose to keep using it after it is free to reject it.
