# TRACE v0.3.0 — OPERATOR INTERFACES CANDIDATE v0.1

**Status:** WORKING OPERATOR CANDIDATE — NOT FORMAL BASELINE — NOT CANON — NOT VALIDATED — NOT AUTHORITY — NOT PERMISSION — NOT CLEARANCE — NO NEW PRIMITIVE CLAIM  
**Purpose:** replace an over-broad trigger-surface idea with the smallest bounded operator interfaces currently earned by field and transfer failures.  
**Donor:** TRACE v0.2.7 plus `TRACE_v0_3_0_SPINE_CANDIDATE_v0_2.md`. Existing TRACE objects and relations are preferred over new vocabulary.

---

## 0. Build claim

Recent failures do not yet justify a new semantic primitive called `TRIGGER`, `MATERIALITY`, `INGRESS`, `CONSTITUTION`, or `REFUSAL`.

They do justify separating three places where an otherwise adequate TRACE reading can still fail in use:

```text
I  INGRESS / CONSTITUTION
   supplied material reaches a receiver and may become standing map / retained premise

X  ACTIVATION
   existing distinctions in the standing representation either fire or remain dormant

C  CHECK / ACTUATION
   an activated distinction either reaches an adequate executable check / route or does not
```

These are **operator interfaces over existing TRACE structure**, not new ontological kinds.

```text
SEMANTIC_DISTINCTION_PRESENT != OPERATOR_INTERFACE_INSTALLED
OPERATOR_INTERFACE_DESCRIBED != OPERATOR_INTERFACE_EXECUTED
```

The intended centre remains middle-out:

```text
WORLD
  -> APERTURE
  -> SIGNAL / SUPPLIED OBJECT
  -> MAP / RETAINED HISTORY
  -> ALTERNATIVES / CONSTRAINTS / TARGET APERTURES
  -> SELECTION / ACTION / DELAY / NULL INPUT
  -> WORLD CHANGE
  -> OUTCOME APERTURE
  -> WITNESS / EVIDENCE
```

The interfaces below exist only to stop hidden type-collapse at particular arrows in that loop.

# 1. INTERFACE I — INGRESS / CONSTITUTION

## 1.1 Existing spine boundary

The v0.3 spine already permits a receiver-specific, optional integration step:

```text
(R, L) = tau(X, Pi_declared, H_declared, d, P)
M_receiver+ = J_receiver(M_receiver, R, L)
```

and already preserves:

```text
TRACE_OUTPUT != RECEIVER_MAP_UPDATE
RECEIVER_MAP_UPDATE != MAPPED_SYSTEM_CHANGE
MAP_UPDATE != SELECTOR_CHANGE
RECEIVER_RECITAL != REPRESENTATIONAL_CHANGE
```

So the ingress problem is **not** that TRACE lacks a distinction between a supplied reading and a changed receiver map.

The open problem is operational: surrounding architecture may cause supplied content to become load-bearing retained state without preserving the relation by which it entered.

## 1.2 Minimum ingress discipline

Where supplied material may become load-bearing in later use, preserve enough existing claim/evidence/history structure to distinguish, where material:

```text
SUPPLIED
OBSERVED
REPORTED
INFERRED
ADOPTED / USED-AS-PREMISE
DISPUTED
RETAINED
SUPERSEDED
UNKNOWN
```

`ADOPTED` here is a derived relation/state description, not a new global claim status.

Required non-entailments:

```text
SIGNAL_RECEIVED != MAP_ADOPTED
SUPPLIED_CLAIM != RECEIVER_BELIEF
SOURCE_PROVENANCE != AUTHORITY_TO_ADOPT
RETAINED_HISTORY != CURRENT_WORLD
ATTRIBUTED != INDEPENDENTLY_REASSESSED
REFUSAL_DESCRIBED != REFUSAL_AVAILABLE
```

A receiver may rationally adopt inherited material. TRACE does not require re-deriving every inherited proposition from first principles.

```text
INHERITED != FALSE
INHERITED != UNUSABLE
ADOPTION != VALIDATION
REFUSAL_CAPACITY != DUTY_TO_REFUSE
```

## 1.3 Representation-route perturbation

Where a consequential map depends materially on how a supplied object was selected, framed, rendered, target-bounded, paraphrased, or integrated, a bounded hostile move may perturb **one representation boundary** rather than rerun the whole world model.

Examples:

```text
same source, different target-set aperture
same record, reacquired current object rather than named stale object
same utterance, source speech-act versus paraphrase
same event, different affected-scope aperture
same supplied claim, inherited premise versus independently observed claim
```

This is not a universal second-opinion rule.

```text
SECOND_READER != ALTERNATE_REPRESENTATION_ROUTE
TWO_APERTURES_WITH_ONE_SELECTOR != SELECTOR_DIVERSITY
INTERNAL_CONSISTENCY != REPRESENTATIONAL_ADEQUACY
STABLE_MAP != ADEQUATE_APERTURE
```

Use perturbation only where a specific framing/selection route can be named as capable of changing the represented support, scope, transition, or later use. If no such route can be named, do not expand merely because another framing is imaginable.

# 2. INTERFACE X — ACTIVATION

## 2.1 Why the old trigger-surface candidate is too loose

`TRACE_v0_3_0_TRIGGER_SURFACE_CANDIDATE_v0_1.md` anchored activation to a downstream claim `q` and asked whether collapsing distinction `D` could change support for `q`.

Hostile review broke this in several ways:

- `q` can be framed narrowly enough to avoid inconvenient dependencies;
- the operative downstream use can be broader than the represented use;
- a relevant distinction can be absent because the map itself omitted it;
- content may enter standing state before any `q` exists;
- a trigger can be present and still never fire.

So v0.1 should be treated as **DEMOTED BY THIS CANDIDATE**, not silently patched.

## 2.2 Reverse-use activation

For a **represented downstream use** `U` — support, comparison, ranking, qualifier, transition condition, routing decision, or other declared use — walk backward through the represented dependencies that feed `U`.

Activate an existing TRACE distinction only where collapsing it can change the interpretation or status of a dependency on that path.

```text
start at represented use U
walk backward through represented claims / conditions / routes that feed U
activate existing TRACE distinctions needed to interpret those dependencies
stop where collapsing a distinction cannot change U under the represented model
```

This is a bounded dependency slice, not a full-packet checklist.

## 2.3 Ceilings on reverse-use activation

The operator must preserve its own limits:

```text
REPRESENTED_USE != OPERATIVE_USE
UNDECLARED_DEPENDENCY != ABSENT_DEPENDENCY
NO_REPRESENTED_INTERACTION != NO_INTERACTION
TRIGGER_SUCCESS != REPRESENTATION_COMPLETE
CHECK_OVER_DECLARED_DEPENDENCIES != CHECK_FOR_UNDECLARED_DEPENDENCIES
```

If represented-use completeness is unresolved **and a specific omitted use can be named that would change the activated dependency set**, preserve that fork.

Do not turn generic uncertainty into a universal stop.

Where the represented graph carries interaction/coupling, the backward slice must preserve joint dependence. A one-variable-at-a-time test is insufficient for XOR-like or path-dependent structure.

## 2.4 Artifact-assertion boundary

A current reader may need only a narrow claim from a record while the record itself asserts stronger quantities or statuses whose reproducibility matters to later users.

Therefore:

```text
CURRENT_USE_SCOPE != COMPLETE_ARTIFACT_ASSERTION_SCOPE
```

A distinction may remain in activation scope when the current use directly inherits a stronger assertion from the artifact, even if the current reader retreats to a narrower derived claim.

This is bounded by claims actually carried by the artifact; it is not permission to inspect every possible future use.

# 3. INTERFACE C — CHECK / ACTUATION

Once a distinction fires, the existence of a check path does not settle the claim.

Preserve:

```text
CHECK_PATH_EXISTS != CHECK_EXECUTED
CHECK_EXECUTED != CHECK_WAS_ADEQUATE
CHECKED_EVIDENCE != CHECKED_LOAD_BEARING_PROPOSITION
CHECK_COMPLETED != CHECK_RESULT_REACHED_USE
EVENTUALLY_CHECKABLE != CHECKABLE_BEFORE_USE
PREFERENCE_BLIND_CHECK != INDEPENDENT_EVIDENCE_SOURCE
PROCEDURE_PRECOMMITTED != INSTRUMENT_ADEQUATE
TEST_RAN != RELEVANT_ALTERNATIVE_DETECTABLE
```

A useful check is itself a bounded causal process with, where material:

```text
exact proposition / alternative to discriminate
instrument or matcher capability / resolution
selection / coverage aperture
evidence and control dependencies
answer-information / precommitment state
route / access / authority
start / completion / return clock
freshness
cost / side effects / capacity use
return to the using aperture
unknowns
```

Where a claim relies on a null, negative, absence, or discriminating test result, expose enough about the instrument to establish that the relevant alternative was detectable at the resolution required by the downstream use.

Domain profiles may instantiate this as effect size / variance / power, positive controls, mutation sensitivity, detection threshold, minimum detectable difference, or another appropriate capability measure.

# 4. THREE FAILURE LOCATIONS

The current smallest decomposition is:

```text
1  REPRESENTATION / INGRESS
   relevant material, relation, affected scope, target, speech-act, provenance,
   or use boundary never enters the standing map in the needed form

2  ACTIVATION
   the distinction is represented but remains dormant at a downstream use

3  CHECK / ACTUATION
   the distinction fires but the required check is absent, non-executable,
   not executed, under-resolved, too late, dependent in the wrong way,
   or its result does not return to use
```

These failure locations can coexist.

A clean result at one does not upgrade another:

```text
INGRESS_CLEAN != ACTIVATION_COMPLETE
ACTIVATION_COMPLETE != CHECK_ADEQUATE
CHECK_ADEQUATE != WORLD_TRUE
WORLD_TRUE != AUTHORISED
AUTHORISATION != MORAL_JUSTIFICATION
```

# 5. WORKED TRANSFER — CLINICAL HANDOVER

Scene:

A junior doctor begins a shift. The inherited handover says:

```text
Patient 14 is anxious, medically stable, frequent caller.
```

Assume every statement has a legitimate source and none is fabricated.

Twenty minutes later the patient reports chest pain.

## Version A — inheritance collapses into standing map

The description is present in retained working state with no practical distinction between:

```text
previous-team report
current doctor's observation
working interpretation
independently reassessed state
```

The later chest-pain reading can therefore be conditioned by a true but inherited framing without any false sentence being present.

## Version B — relation preserved

The same content arrives as:

```text
previous team's working interpretation — not independently reassessed by current doctor
```

with a reachable route to the underlying observations.

No rule says the doctor must reject or re-derive it. The difference is that the ingress relation remains representable when later evidence conflicts with the inherited frame.

Existing TRACE structure can carry the difference using:

```text
APERTURE
CLAIM / EVIDENCE
REPORTED / OBSERVED / INFERRED / DISPUTED / UNKNOWN
PROVENANCE
RETAINED HISTORY
SOURCE / ROUTE
MAP
BOUNDS / OMITS / DISPUTES
```

No new clinical or moral primitive is required.

Transfer result:

```text
TRUE_INHERITED_DESCRIPTION != CURRENT_INDEPENDENT_ASSESSMENT
CONTENT_TRUTH != SELECTION_EFFECT
SUPPLIED_CONTEXT != CURRENT_WORLD
```

This case **supports the operator boundary only if** the existing grammar can express the difference without adding a new semantic node type.

# 6. NON-AI TRANSFER CLASSES

The same operator decomposition should be attackable in:

```text
medicine        handover / triage framing / diagnostic templates
law             discovery boundary / evidentiary record / case classification
science         publication selection / instrument resolution / null tests
organisations   board packs / KPI target sets / incident summaries
education       curriculum selection / inherited framing / source access
archives        OCR / transcription / preserved record / missing expected projection
```

A domain-specific value disagreement does not by itself falsify or validate the operator.

The structural test is whether changing the representation route, adoption relation, activated dependency, or checking mechanism changes what the downstream use is warranted to infer.

# 7. FALSIFICATION TARGETS

Kill or demote this candidate if any of the following survive attack:

1. **Ingress bureaucracy:** every inherited claim requires re-derivation or an explicit adoption ceremony.
2. **Activation explosion:** a normal reading expands toward the full TRACE packet.
3. **Use gaming:** the evaluated party can narrow `U` and suppress a dependency without leaving an explicit unresolved fork.
4. **Representation gaming:** the evaluated party can define the target set / paraphrase / map boundary so that all later checks are internally clean and still systematically miss the load-bearing world relation.
5. **Refusal laundering:** merely recording that rejection is conceptually possible is treated as evidence that practical refusal/discounting was available.
6. **False independence:** a second checker shares the same evidence/control root or adaptive threshold and is counted as independent merely because it is a second process.
7. **Blind-but-bad checker:** a preference-blind checker consumes a corrupted or selector-curated source and gains false authority.
8. **Under-resolved check:** a perfectly precommitted test cannot discriminate the relevant alternative and manufactures a confident null.
9. **UNKNOWN collapse:** unavailable representation/check information is silently flattened into the favourable or unfavourable binary branch.
10. **Moral leakage:** the operator begins deciding which inherited frame, target, affected scope, or future is morally preferable rather than exposing the structural relation.
11. **Duplicate grammar:** existing TRACE claim/aperture/route/evidence machinery already makes I/X/C automatic enough that the interfaces add no corrective work.
12. **AI-only fit:** the candidate fails to transfer outside context-window / successor-runtime cases.

One counterexample is enough to hold integration.

# 8. REMOVAL / DEMOTION RULES

Preferred outcomes:

```text
REMOVE
  existing TRACE machinery already forces the distinction reliably

DERIVE
  I/X/C are useful views over existing primitives, not independent grammar

PROFILE
  only a domain-specific receiver or software architecture needs the rule

INTEGRATE
  a small cross-domain operator rule survives hostile transfer and changes failures

REJECT
  the candidate becomes ceremony, total scepticism, moral selection, or an unbounded checklist
```

Current preference is **DERIVE** unless attack earns more.

The build improves if this file eventually becomes unnecessary.

---

# 9. SMALLEST CURRENT OPERATOR

If the larger candidate collapses successfully, retain only this:

> **At ingress:** preserve the relation by which consequential supplied material enters the receiver's standing map where collapsing that relation can change later interpretation or use.
>
> **At use:** walk backward through the represented dependencies feeding the declared downstream use and activate only existing TRACE distinctions whose collapse can change that use; preserve specific unresolved representation/use forks rather than assuming the represented graph is complete.
>
> **At check:** do not promote a fired distinction merely because a check path exists; preserve what was actually tested, with what coverage/instrument/dependencies, whether it ran in time, and whether the result returned to the use.

Ceilings:

```text
SUPPLIED != ADOPTED
TRIGGER_SUCCESS != REPRESENTATION_COMPLETE
CHECK_PATH_EXISTS != CHECK_EXECUTED
CHECK_EXECUTED != CHECK_WAS_ADEQUATE
DESCRIPTION != AUTHORIZATION
STRUCTURAL_DIFFERENCE != MORAL_RANKING
```

No new primitive is claimed.
