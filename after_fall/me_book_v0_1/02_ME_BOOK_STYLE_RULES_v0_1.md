# Mechanical Ethics Book Style Rules v0.1

Status: working style rules. Candidate only. Not canon, validation, proof, permission, clearance, compliance, legal advice, or release.

## 1. Book texture

The book should read like a serious short human book, not a framework manual.

```trace
texture := human_scene + plain_argument + structural_anchor
```

Default order:

```text
scene first
claim second
structure third
```

Do not start chapters with definitions unless the chapter genuinely needs it.

## 2. Sentence style

Use plain sentences.

Prefer:

```text
The route existed. She still could not use it.
```

Avoid:

```text
This illustrates a multi-layered procedural accessibility deficiency in the available remedial pathway.
```

## 3. Repetition is allowed

Certain sentences should recur with variation because they are load-bearing:

```text
A door a person cannot reach is not a door in their world.
Help must land before the loss sets.
Correction is not time travel.
The maze is not neutral when the institution built it.
A record is not justice, but disappearance is worse.
If the harmed person still pays, the debt is open.
```

## 4. Glyph and formula use

Glyphs and formulas are allowed only as compact anchors after the human meaning is clear.

```trace
glyph_density := low
```

Forbidden:

```text
opening a chapter with dense notation
using formulas to replace moral explanation
using symbols as authority theatre
```

Allowed:

```text
a short structural anchor at the end of a section
a small legend in an appendix
a repeated inequality where timing is central
```

## 5. Case examples

Examples should be generic enough to avoid false factual claims unless sourced later.

Use fictional composites where necessary:

```text
a tenant
a claimant
a worker
a parent
a patient
a platform user
a public servant inside the machine
```

If using real cases later, add source discipline separately.

## 6. No overclaiming

Never say:

```text
Mechanical Ethics proves...
TRACE shows the correct answer...
The framework validates...
This would solve...
This guarantees safety...
```

Prefer:

```text
This gives us a way to see...
This makes it harder to hide...
This does not settle the matter...
This records what remains open...
```

## 7. Human but not sentimental

The book should care about people without using melodrama.

Prefer concrete burden:

```text
three phone calls
one missed shift
a damp wall
a form that cannot be understood
a deadline controlled by the other side
```

Avoid abstract pity.

## 8. Strong claims should be earned

A strong moral sentence should usually come after a scene, not before it.

Bad order:

```text
The institution laundered harm. Here is an example.
```

Better order:

```text
The route existed. The tenant could not use it without risking eviction. The file later said no complaint had been made. That is how harm is laundered through process.
```

## 9. Keep the book separate from holder-contact machinery

Do not turn the book into the Witness Pack guide.

The book may explain why witness matters. The packet explains how to record it.

```trace
ME_book := meaning
Witness_Pack := tool
```

## 10. Drafting rule

Each chapter should include:

```text
opening scene
central claim
one or two supporting examples
plain-language structural explanation
short closing sentence
optional compact anchor
```

End.
