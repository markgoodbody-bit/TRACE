## Scope of verdict

This means Chapter 11 is book-shaped and structurally useful, but it needs a narrow patch before it should be treated as passing the same voice threshold as Chapters 1-10.

It does not mean final, canon, validation, proof, release, or external readiness.

## Why it mostly works

### 1. The opening is strong

```text
The second person meets the same failure.
```

This is the right opening. It makes repeat harm visible through recurrence, not theory.

### 2. The machine-survival line is strong

```text
The second person does not meet the first person's case.

They meet the machine that survived it.
```

This should remain. It is the chapter's best compression.

### 3. The event/output distinction works

```text
But when a system produces the same burden again after it has already been shown where the burden lands, the harm is no longer only an event.

It has become output.
```

This carries the Part IV machine frame without becoming too technical.

### 4. The learning/apology distinction is clear

```text
Learning is not a better apology.

Learning is changed behaviour.
```

This should remain. It is the chapter's moral hinge.

### 5. The repeated-apology passage works

The repeated "we are sorry" section is effective because it shows care-language becoming evidence that care has not reached the mechanism.

### 6. The memory/surveillance caveat is necessary

The chapter correctly refuses data-hoarding and people-as-trouble memory:

```text
Not a memory that hoards personal data without purpose.

Not a memory that labels people as trouble.

Not a memory that makes surveillance easier.
```

This protects the argument from drifting into surveillance-as-answer.

### 7. The ending points correctly to correction theatre

```text
The next chapter is about what happens when correction language survives even though correction does not reach the mechanism.

That is correction theatre.
```

This is a clean bridge.

## Why it does not get full pass yet

### 1. It is too abstract after the opening

The opening is human, but the middle becomes concept-heavy. It has examples, but many are category examples rather than lived detail.

Patch need: add one concrete recurring-case object near the first third: a second tenant uploading the same photograph, a second worker using the same safety line, a second claimant copying the same reference number, or a second parent receiving the same stock letter.

### 2. Title ambiguity remains live

```text
Repeat Harm Is Not Responsibility
```

This title can be misread. The intended meaning is not that repeat harm lacks responsibility. The intended meaning is that repeated apology, repeated explanation, and repeated case-by-case correction are not responsibility.

Possible later title alternatives:

```text
Repeated Apology Is Not Responsibility
The Machine Has Not Learned
When the Same Burden Returns
Learning Is Changed Behaviour
```

No rename yet, but the ambiguity is real.

### 3. Aphorism density is high

The chapter has many strong short sentences. Several work. Together they begin to feel close to doctrine.

Patch need: one embodied paragraph will reduce this by restoring scene pressure.

### 4. Chapter 12 must be protected

Chapter 11 already uses the word theatre and identifies unchanged mechanism. Chapter 12 must not simply repeat this. It must distinguish correction theatre as public/performed correction language after mechanism failure, not merely repeated apology.
