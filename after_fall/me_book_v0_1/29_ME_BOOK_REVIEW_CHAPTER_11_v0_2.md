## Scope of verdict

This means Chapter 11 v0.2 has a viable book voice and now clears the immediate patch warning from v0.1. It successfully carries repeat harm as machine output while keeping the chapter human-facing.

It does not mean final, canon, validation, proof, release, or external readiness.

## Why it now passes

### 1. The embodied patch works

The inserted paragraph gives the chapter a body before it moves into machine language:

```text
The second person takes a photograph of the same kind of problem and tries to send it through the same narrow route. The file size is wrong. The category is wrong. The reference number belongs to another team. Lunch ends before the call is answered. They write the number on the back of an envelope because the portal will not show it again.
```

This fixes the main v0.1 defect. The chapter now gives the reader a person encountering repeated machinery, not just a proposition about repeated machinery.

### 2. The machine-survival line still lands

```text
The second person does not meet the first person's case.

They meet the machine that survived it.
```

This remains the chapter's strongest compression. Keep it.

### 3. The event/output distinction is preserved

```text
But when a system produces the same burden again after it has already been shown where the burden lands, the harm is no longer only an event.

It has become output.
```

The added embodied paragraph now makes this distinction feel earned rather than abstract.

### 4. The caveats survived

The chapter still protects against overclaiming:

```text
A single repeat does not prove a system is malicious, careless, or broken beyond repair.
```

It also preserves the case-specificity caveat:

```text
Difference matters. A pattern should not erase detail.
```

These are necessary. They stop the argument from becoming a blunt pattern accusation.

### 5. Learning remains behaviour, not language

```text
Learning is not a better apology.

Learning is changed behaviour.
```

This remains the hinge. It is plain enough for the book and strong enough for Part IV.

### 6. The apology caveat remains intact

```text
Not because apology is worthless. A real apology can matter.
```

This keeps the chapter from becoming anti-apology. The problem is repeated apology over an unchanged mechanism, not apology itself.

### 7. The responsible-memory section remains safe

The chapter still refuses surveillance as the answer:

```text
Not a memory that hoards personal data without purpose.

Not a memory that labels people as trouble.

Not a memory that makes surveillance easier.
```

This is essential. It prevents the chapter from drifting into data-hoarding as moral repair.

### 8. The ending correctly preserves Chapter 12 space

```text
The next chapter is about what happens when correction language survives even though correction does not reach the mechanism.

That is correction theatre.
```

Chapter 11 now hands off rather than fully consuming Chapter 12.

## Remaining small issues

These do not block the verdict.

### 1. Title ambiguity remains a watch item

```text
Repeat Harm Is Not Responsibility
```

The title is still slightly ambiguous. It is acceptable for now because the chapter body clarifies the intended claim, but a later title pass should reconsider it.

Possible alternatives remain:

```text
Repeated Apology Is Not Responsibility
The Machine Has Not Learned
When the Same Burden Returns
Learning Is Changed Behaviour
```

### 2. The chapter is still dense

The v0.2 patch improves the body of the opening. Later line edit may still trim aphorism density in the middle, but this is no longer a blocker.

### 3. Chapter 12 must distinguish theatre from repeat harm

Chapter 12 should not merely repeat Chapter 11. It should focus on performed correction: reports, reviews, apologies, learning statements, public concern, labels, process improvement language, and symbolic repair that leaves burden/mechanism unmoved.
