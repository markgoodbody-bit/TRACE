## Scope of verdict

This means Chapter 9 has a viable book voice and successfully closes Part III by naming residue: the cost still carried after official correction.

It does not mean final, canon, validation, proof, release, or external readiness.

## Why it passes

### 1. It starts with official completion

```text
The correction is recorded as complete.
```

This is the right opening. It begins where the system thinks the matter has ended.

### 2. It immediately returns to the person still paying

```text
But the person is still paying.
```

This is the chapter's moral turn. It moves from completed action to remaining burden.

### 3. The residue definition is clear

```text
Correction can close a file before it closes the debt.

That is residue.
```

This is a strong definition. It is plain, memorable, and human-readable.

### 4. It avoids compensation-calculus drift

The chapter explicitly refuses the false claim that all residue has a clean remedy:

```text
Some losses cannot be priced without lying.
```

This keeps the chapter serious. It names open debt without pretending every remainder can be converted neatly into payment.

### 5. The anti-laundering distinction works

```text
There is a difference between a loss that cannot be fully repaired and a loss that has been erased from the account.
```

This is one of the chapter's strongest lines. It should remain.

### 6. The file/life pattern works here but should now rest

The pattern is effective:

```text
The file says: remedy provided.

The life says: I am still paying.
```

It works because Chapter 9 is closing a movement. But Part IV should reduce this pattern sharply to avoid mechanical repetition.

### 7. The gratitude/closure passage is necessary

```text
Gratitude can be demanded too early. Closure can be requested too cheaply. Reconciliation can be staged while the person is still paying.
```

This is important. It names a common post-correction pressure without becoming sentimental.

### 8. The disposal-site line is strong

```text
It is a refusal to let the person become the disposal site for whatever correction did not reach.
```

This should remain. It gives residue its moral force.

### 9. The Part III close works

```text
Witness can preserve. Custody can protect. Residue can name what remains open.

But none of that explains why the machinery keeps producing these burdens in the first place.

The next part turns to the machine.
```

This is a clean structural handoff into Part IV.

## Remaining small issues

These do not block the verdict.

### 1. Watch repetition of "paying"

The repetition is intentional and effective early. Later line-edit pass may trim one instance if the opening feels over-insistent.

### 2. The file/life pattern should pause

Part IV should not keep using the same file/life device as a default. The book needs new machinery language now.

### 3. Part IV must not become technical spec

The next section turns to complexity, repeat harm, and correction theatre. It should stay book-like and human-facing, not slide into framework documentation.
