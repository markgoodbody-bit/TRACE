## Scope of verdict

This means Chapter 14 has a viable book voice and successfully carries Part V forward from false reconciliation into open remainder, memory, custody across time, and future obligation.

It does not mean final, canon, validation, proof, release, or external readiness.

## Why it passes

### 1. It starts with administrative closure

```text
The file is closed.
```

This is the right opening. It begins with the official claim of completion, then tests that closure against what remains.

### 2. The core claim lands early

```text
A responsible system does not erase what it cannot repair.
```

This is the chapter's load-bearing sentence. It should remain.

### 3. It avoids endless-punishment drift

The chapter explicitly blocks the wrong reading:

```text
Not because the system must be punished without end.
```

and later:

```text
Open does not mean infinite.

Open means not falsely closed.
```

This is necessary. It makes open remainder disciplined rather than punitive.

### 4. The open-remainder taxonomy is useful but still book-like

```text
This was repaired.

This was partly repaired.

This was acknowledged but not repaired.

This was changed for the future but not restored for the person already harmed.
```

This section gives the reader a clean way to understand partial repair without turning the chapter into a manual.

### 5. Ethical memory is well handled

```text
The burden should not travel with the person as stigma.

It should travel with the system as obligation.
```

This is one of the chapter's strongest lines. It should remain.

### 6. Custody across time works

The chapter correctly moves from memory to safe memory:

```text
Custody is not only where the record lives.

It is how the record survives without becoming another weapon.
```

This protects the book from naive archive-as-answer thinking.

### 7. The pain-memory line is strong

```text
A system that depends on the harmed person repeatedly reopening themselves has not built answerability. It has outsourced memory to pain.
```

This is a central Chapter 14 line. Keep it.

### 8. Administrative closure is separated from moral closure

```text
Administrative closure must not pretend to be moral closure.
```

This is plain and useful. It also avoids demanding that every case stay administratively active forever.

### 9. The forward motion works

The chapter does not merely keep the wound open. It gives open remainder forward motion:

```text
The question is not only what happened.

The question is what must now be different because it happened.
```

This is the correct bridge to Chapter 15.

## Remaining small issues

These do not block the verdict.

### 1. Chapter is long and slightly accumulative

The chapter has many parallel sequences. They work, but a later line edit may trim one cluster around successor obligation or closure forms.

### 2. Watch capitalization typo

Line-edit later:

```text
software is replaced
```

should become:

```text
Software is replaced
```

No standalone patch needed now.

### 3. Final chapter must compress, not expand

Chapter 15 should not add another diagnostic layer. It should compress the book into a human standard for answerability.
