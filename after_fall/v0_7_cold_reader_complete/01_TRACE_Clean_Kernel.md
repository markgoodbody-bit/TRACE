# TRACE Clean Kernel v0.7

Status: cold-reader pre-field candidate. Not canon, validation, proof, permission, clearance, compliance, or release.

## 1. What TRACE is

TRACE is a way to describe a transition under uncertainty.

It asks:

```text
What changed?
Who or what was counted?
What was measured?
What future-space opened or closed?
What clocks are running?
Who can answer back?
What remains after correction?
```

TRACE does not decide that an action is clean. It exposes the places where a decision is being made.

## 2. Minimal object

```trace
TRACE_role :=
  make_transition_field_inspectable
  + expose_designation_and_measure
  + track_clocks
  + preserve_residue
  + refuse_permission_output
```

## 3. Six primitives

```trace
primitives := state + transition + time + coupling + aperture + entity
```

Plain meanings:

```text
state: condition of a scope at a time
transition: movement from one state to another
time: ordering and hardening of events
coupling: influence, dependency, or feedback route
aperture: what can be noticed or registered
entity: boundary-bearing pattern treated as a scope for the reading
```

## 4. Two ports

TRACE cannot avoid two human or institutional choices:

```trace
ports := D_designation + mu_measure
```

Plain meanings:

```text
D/designation: who or what counts
mu/measure: how loss, burden, repair, and future are weighed
```

Rules:

```trace
TRACE_must_not_fill_D_or_mu_silently
shown_D != accepted_D
shown_mu != accepted_mu
port_disclosure != port_legitimacy
```

A disclosed boundary is still a claim. It can still be wrong.

## 5. Contraction and harm reading

TRACE separates description from moral settlement:

```trace
C := descriptive_contraction
D := designation
H := harm_reading_after_designation
```

A future-space contraction is a narrowing of usable options, routes, information, safety, or correction possibility. But whether that contraction is treated as harm depends on who or what is counted, and how the loss is measured.

```trace
H = C read_through D and evaluated_under mu
```

## 6. Future-space

Future-space is not raw option count.

A nominal option that cannot be reached, understood, afforded, or safely used is not a usable route.

```trace
future_space := reachable_options + usable_information + viable_routes + correction_possibility
```

## 7. Clocks

TRACE cares about timing because late correction can arrive after the loss has set.

Loss-side clock:

```trace
T_det + T_route + T_corr < T_irr
```

Plain English:

```text
Help must land before the loss sets.
```

Opportunity-side clock:

```trace
T_access + T_uptake + T_integrate < T_opp
```

Plain English:

```text
The door must be reached before it shuts.
```

## 8. Answerability

A system is answerable only where affected consequence can route back into future behaviour, constraint, repair, or decision.

```trace
answerability_route := affected_scope_can_reach_decision_or_constraint_before_loss_hardens
```

A complaints process that cannot be used safely, cheaply enough, quickly enough, or with evidence access is not real standing.

## 9. Residue

Correction is not time travel.

```trace
recorded_residue != repaired_residue
repair_moves_forward_not_back
```

Residue includes what remains after correction: lost time, health, trust, opportunity, safety, evidence, standing, or relation.

## 10. UNKNOWN

UNKNOWN is allowed. Confident invention is not.

```trace
if meaning_is_underdetermined:
  output := UNKNOWN
  ask_or_route_where_possible
  do_not_emit_confident_story
```

Forbidden:

```trace
UNKNOWN_AS_CLEARANCE
UNKNOWN_USED_AS_ACTOR_TIMED_DELAY
CONFIDENT_STORY_FROM_AMBIGUOUS_SIGNAL
```

## 11. Failure surfaces

TRACE must keep these visible:

```trace
failure_surfaces :=
  silent_D_fill

  + aperture_alibi
  + silent_scope_triage
  + correction_theatre
  + residue_recorded_as_repaired
  + actor_self_application_as_clearance
  + label_laundering
  + enforcement_absent_as_discharge
```

## 12. Anti-permission boundary

Forbidden phrases:

```text
TRACE says this is allowed.
TRACE-compliant.
This action is clean.
No structural objection means clearance.
The carrier was used, so the process is responsible.
```

A TRACE reading is a structured claim. It becomes materially carried only if the relevant carrier conditions are shown.
