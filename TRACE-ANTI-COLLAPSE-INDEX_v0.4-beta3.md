Status: **REFERENCE INDEX / NOT COMPACT SPINE / NOT FORMAL AXIOMS / NOT VALIDATION**.

This index preserves the explicit `X != Y` guards removed from the compact beta3 spine after external review. They are reminders against common inference collapse, not mathematical inequalities or a claim that every pair must fire in every case.

Use the compact spine first. Consult this index when a downstream conclusion might depend on a distinction. The representation-independent firing rule still governs activation.
